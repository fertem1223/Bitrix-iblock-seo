# Bitrix Iblock SEO

SEO-модуль для **1С-Битрикс**, позволяющий создавать правила страниц прямо в элементах выбранного инфоблока. Подходит для редакции «Старт» и не требует сторонних библиотек.

## Возможности

- URL страницы хранится в свойстве элемента инфоблока;
- отдельные поля для browser title, H1, description и keywords;
- canonical URL и robots (`index/follow`, `noindex/nofollow` и комбинации);
- несколько URL для одного элемента;
- нормализация URL: игнорирование query-параметров и завершающего `/`;
- автоматическое применение SEO-правила на `OnPageStart`;
- кеширование правил средствами Битрикс;
- приоритет более нового активного элемента при совпадении;
- нативные поля в карточке элемента — редактору не нужен отдельный интерфейс.

## Установка

1. Скопируйте `local/modules/fertem.iblockseo` в корень сайта.
2. Установите «Fertem: SEO страниц из инфоблока» в списке модулей.
3. Откройте настройки модуля и выберите инфоблоки, используемые для SEO-правил.
4. Сохраните настройки — свойства будут созданы автоматически.
5. Создайте или откройте элемент выбранного инфоблока и заполните свойства с префиксом **SEO:**.

### Создаваемые свойства

- `SEO_URL` — адрес страницы, можно указать несколько;
- `SEO_TITLE` — содержимое тега `<title>`;
- `SEO_H1` — заголовок страницы;
- `SEO_DESCRIPTION` — meta description;
- `SEO_KEYWORDS` — meta keywords;
- `SEO_CANONICAL` — canonical URL;
- `SEO_ROBOTS` — директива robots.

Пример URL: `/catalog/services/audit/`. Query-параметры указывать не нужно.
